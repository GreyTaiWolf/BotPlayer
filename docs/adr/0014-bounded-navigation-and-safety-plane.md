# ADR-0014：有界导航快照、分段路径与独立安全平面

- 状态：Accepted
- 日期：2026-07-29

## 背景

P2 已提供真实玩家输入和世界交互，P3 已提供有限感知，但二者都不能直接承担长距离导航
或下一 Tick 的致命危险反射。导航需要较大的局部运动网格；如果把它塞进 P3 认知快照，
会破坏有限感知边界。反过来，如果 L0 依赖可降频的 P3 快照，又无法及时阻止 bot 走入
熔岩、悬崖或爆炸范围。

## 决策

1. P4 使用只读已加载区块的不可变运动快照，并以有界、确定性的分段 A* 规划路线。
2. 世界与实体只在服务器主线程采样；规划线程只读取 primitive、ID、enum 与不可变数组。
3. 运动网格是内部控制数据，不进入 P3 世界事实、LLM 上下文或长期记忆。
4. 长目标通过滚动局部 frontier 推进；未知区块保持未知，不强制加载，也不当成空气。
5. follower 只通过 P2 动作与玩家输入驱动真实 `BotServerPlayer`，不得传送或直接写速度。
6. L0 使用每 Tick、常量上限的独立 `SafetyFrame`，不因 P3 或导航压力降级。
7. 安全反射通过现有动作优先级抢占导航；generation、死亡、换维度和停服会关闭两者状态。
8. 挖掘与搭桥默认关闭，必须同时通过请求和服务器策略，且每次真实修改后重新规划。
9. 伤害、药水、状态效果和属性继续由真实玩家身体与 NeoForge 事件链结算；P4 只观察最终
   身体结果并采取通用保守反应。

## 被否决方案

- 直接复制或嵌入 Baritone：与许可证、玩家动作层和现有 generation 架构不匹配。
- 使用 Mob `PathNavigation`：BotPlayer 主体必须保持 `ServerPlayer`，不能改成 Mob。
- 首版采用 D* Lite：没有重算性能证据，会提前引入持久搜索状态和复杂失效传播。
- 使用 P3 快照充当 L0：采样可能降频或截断，不能作为致命危险的唯一输入。
- 为导航强制区块票或扫描远处世界：破坏服务器公平和有限认知边界。

## 兼容性、性能、安全与许可证影响

- 单快照、节点扩展、规划队列、重算、恢复和世界修改均有硬上限。
- 未知、截断、过期或异常状态默认停止或重算。
- 运动快照没有 Minecraft 活动对象，允许在受限执行器中规划。
- 本实现只借鉴公开算法与行为语义，没有复制第三方源码，也没有新增运行时依赖。
- 标准模组 `DamageType`、`MobEffect`、属性和玩家 Tick 仍作用于真实身体；专用语义适配
  仍属于 P8。

## 迁移和回滚

P4 数据只存在于运行时，不新增世界持久 schema。关闭导航命令或卸载模组即可回滚；已有
roster、playerdata、P2 动作与 P3 世界事实不需要迁移。未来更换规划算法时保持
`RoutePlanner` 和 `RoutePlan` 契约，不持久化 A* 内部 open/closed 集合。

## 验证方式

- 纯 Java 单测固定有界 A* 的确定性、未知边界、预算、取消、溢出和策略约束。
- NeoForge GameTest 验证真实玩家移动、动态封路、危险抢占、仇恨、饥饿、伤害与效果。
- 断言普通导航没有传送、直接改速度、直接改方块或绕过 P2 动作层。
- 同一 GameTest 世界连续运行两轮，并分别记录客户端、专用服和 soak 的未验证边界。
